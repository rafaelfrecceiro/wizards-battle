# Wizards Battle

Repositório: [rafaelfrecceiro/wizards-battle](https://github.com/rafaelfrecceiro/wizards-battle), branch `main`. Código, arte, design e QA são versionados; saves, logs, dependências, segredos e builds geradas ficam locais. Links para `../../ideias/` e caminhos absolutos são referências ao hub de origem e não são necessários em runtime.

Preferência vigente de 27/10/2026: após novas alterações, revisar o diff e arquivos novos e perguntar ao usuário se deseja commitar e publicar. Commit/push dependem de confirmação; automação horária pausada, sem sincronização por horário. Para integrar mudanças, incorporar avanço remoto apenas por fast-forward com árvore limpa. Em conflitos/divergência, interromper e avisar; nunca forçar push nem sobrescrever trabalho. Saves locais não são backup no GitHub.
